# LimpiaPro v2.10.4

## El menu lateral queda solo para navegar

El conmutador de **modo claro / oscuro** que estaba al pie del menu lateral
se ha quitado: ahora el tema se elige unicamente en **Ajustes >
Apariencia**, junto al resto de preferencias (idioma, comportamiento y
ubicaciones). El menu se ocupa solo de navegar entre apartados.

- El tema sigue teniendo las tres opciones: Oscuro, Claro y Sistema (el de
  Windows).
- El cambio se aplica al instante desde Ajustes.

## Descargas

| Archivo | Para que |
|---|---|
| `LimpiaProPortable.zip` | **Recomendado**: portable OneDir, arranque instantaneo |
| `LimpiaPro.zip` | El .exe de un solo archivo, dentro de un zip |
| `LimpiaPro.exe` | Un solo archivo (descarga directa, mas fragil) |
| `LimpiaProDebug.exe` | Variante con consola para diagnostico |
| `SHA256SUMS.txt` | Hashes para verificar la descarga |
